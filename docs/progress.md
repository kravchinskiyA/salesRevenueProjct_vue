- **Суть задачи:** добавлена страница `/sources` и пункт меню «Источники данных» в существующем оформлении ShopAdmin с помощью workflow Build Web Apps. Поддержаны отсутствие отчёта/непроверенные источники. Dev-сервер обновляет страницу при изменении JSON; production требует пересборки. Кеш выручки не менялся.
