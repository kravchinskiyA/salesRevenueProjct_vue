# Правило: Описание проекта (Project Overview)

## Назначение
Контекст предметной области и общая информация о системе `salesRevenueProject`.

## Описание проекта
**salesRevenueProject** (ShopAdmin) — аналитическая панель для мониторинга выручки и транзакций интернет-магазина.

### Основные функции
- Агрегация транзакций из нескольких гетерогенных финансовых источников (`finance1`, `finance2`).
- Конвертация мультивалютных транзакций в базовую валюту (USD) по актуальным или историческим обменным курсам.
- Визуализация динамики выручки и распределения по источникам/валютам (по дням и за месяц).
- Детальный просмотр отдельных транзакций и их статусов.
- Экспорт сводных отчетов в форматы CSV, Excel (XLSX) и изображений графиков (PNG).
