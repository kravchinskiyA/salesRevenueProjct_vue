## Разделение ответственности (Separation of Concerns)
1. **Сетевые вызовы (`src/api/`):** Только HTTP-запросы, заголовки, разбор кодов ошибок. В этот слой не помещается бизнес-логика расчёта.
2. **Конфигурация (`src/config/`):** Статические константы, эндпоинты, ключи кеша, переключатели функциональности (feature-flags).
3. **Бизнес-логика и трансформация (`src/services/`):** Валидация форматов, фильтрация по статусам, денежная арифметика в центах, сборка итоговых моделей отчетов.
4. **Хуки данных (`src/composables/`):** Интеграция с Vue Query, управление staleTime, ключами запросов и кешированием.
5. **Клиентское состояние (`src/stores/`):** Выбранная дата, синхронизация между компонентами интерфейса.
6. **Утилиты (`src/utils/`):** Чистые функции общего назначения: даты, экспорт файлов, форматирование чисел и валют.
7. **Представления и компоненты (`src/views/`, `src/components/`):** Отображение данных, реакция на действия пользователя, вызов composables/stores. Никаких прямых вызовов `fetch` из компонентов.
