# Правило: Кеширование и управление состоянием (Caching and State)

## Назначение
Регламент работы с серверным состоянием (TanStack Vue Query), локальным кешем и клиентским хранилищем Pinia.

## 1. TanStack Vue Query
Все асинхронные запросы данных из внешних API оборачиваются в composables (`src/composables/useRevenue.js`) с использованием TanStack Vue Query.

### Структура ключей кеша (Query Keys)
- Ключ кеша дня: `['revenue', 'day', date]`
- Ключ кеша месяца: `['revenue', 'month', month]`

### Политика свежести данных (staleTime)
- **Исторические дни (прошлые даты):** Считаются неизменяемыми (`staleTime: Infinity`). Повторные запросы не выполняются, если данные уже есть в кеше.
- **Текущий день (сегодня):** Данные считаются свежими в течение 5 минут (`CACHE.todayStaleTime = 5 * 60 * 1000`). По истечении этого времени запрос будет актуализирован в фоне.

## 2. Персистенция в LocalStorage
- Данные кеша сохраняются в `window.localStorage` через `@tanstack/query-sync-storage-persister`.
- Ключ персистенции формируется с версионным маркером: `SALES_REVENUE_CACHE_${CACHE.buster}`.
- **Критическое правило:** При любом изменении структуры хранимых отчётов, нормализации полей или моделей данных **обязательно** инкрементировать версию `CACHE.buster` в `src/config/api.js`. Это предотвратит ошибки чтения устаревшей схемы из браузера пользователя.

## 3. Клиентское состояние Pinia
- Хранилище `src/stores/period.js` отвечает за:
  - Выбранную пользователем дату/месяц.
  - Лимиты навигации календаря (минимальная/максимальная дата с учетом флага `FEATURES.dateSwitching`).
  - Синхронизацию параметров с URL и маршрутизатором Vue Router.
