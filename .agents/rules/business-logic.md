# Правило: Ключевые бизнес-правила и доменная логика (Business Logic)

## Назначение
Регламент финансовых расчетов, валидации транзакций, конвертации валют и поведения источников данных.

## 1. Финансовая точность (Целочисленные центы)
- Запрещены прямые арифметические операции сложения/вычитания над числами с плавающей точкой в JS.
- Все расчеты проводятся через целочисленные центы:
  ```javascript
  const toCents = (v) => Math.round(Number(v) * 100);
  const fromCents = (c) => c / 100;
  ```
- Округление и конвертация выполняются строго по правилам банковского или стандартного округления до центов перед суммированием.

## 2. Расчет выручки (Только оплаченные транзакции)
- В итоговую выручку (Revenue) и валютную аналитику включаются **исключительно** транзакции со статусом `paid` (или строковые транзакции из `finance2`, которые считаются успешными по умолчанию).
- Транзакции со статусами `failed`, `pending`, `cancelled` и др. отображаются в общем списке транзакций для прозрачности аудита, но **не учитываются** в суммах выручки.

## 3. Форматы входящих финансовых источников
- **`finance1`:** Объект вида:
  ```json
  {
    "transactions": [
      { "id": 1, "amount": 120.50, "currency": "USD", "status": "paid" }
    ]
  }
  ```
- **`finance2`:** Массив строк вида:
  ```json
  [
    "120.50 USD",
    "45.00 EUR"
  ]
  ```
- Валидаторы в `src/services/validators.js` строго проверяют типы данных перед передачей в обработку. Некорректные или поврежденные записи отбрасываются или логируются с предупреждением.

## 4. Конвертация валют и обменные курсы
- Источник курсов: сервис `currencyfreaks.com`.
- Для текущего дня используется эндпоинт `/latest`.
- Для прошлых дней используется эндпоинт `/historical?date=YYYY-MM-DD`.
- Базовая валюта отчетов — `USD`. Все суммы в других валютах конвертируются по формуле `amount / rate_to_usd` (в центах).

## 5. Фича-флаг переключения дат (`dateSwitching`)
- Конфигурация находится в `src/config/features.js` (`FEATURES.dateSwitching`).
- Значение по умолчанию: `false` (разрешен просмотр только сегодняшнего дня/месяца, так как внешний учебный API может не поддерживать произвольные исторические даты).
- Включение через переменную окружения: `VITE_FEATURE_DATE_SWITCHING=true`.
