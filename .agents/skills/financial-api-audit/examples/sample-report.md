## 2. Подробный реестр выявленных дефектов и аномалий

### 1. [WARNING] 🟡 Обнаружены посторонние поля верхнего уровня: address
- **Эндпоинт:** `/api/finance1`
- **Код правила:** `UNEXPECTED_ROOT_FIELDS`
- **Ожидалось по спецификации:** `Ответ должен содержать только ключ "transactions"`
- **Фактический ответ сервера:** `Присутствуют поля: ["address"]`
- **Влияние на клиентское приложение:** Загрязнение контракта, утечка нерелевантных персональных/адресных данных (PII).
- **Рекомендация по исправлению:** Удалить посторонние поля или вынести их в отдельный эндпоинт профиля/магазина.

### 2. [WARNING] 🟡 Поле статуса названо "type" вместо общепринятого "status"
- **Эндпоинт:** `/api/finance1`
- **Код правила:** `FIELD_NAME_MISMATCH_STATUS`
- **Ожидалось по спецификации:** `"status": "paid"`
- **Фактический ответ сервера:** `"type": "paid"`
- **Влияние на клиентское приложение:** Нарушение доменной модели, клиент вынужден поддерживать fallback `tx.status ?? tx.type`.
- **Рекомендация по исправлению:** Унифицировать поле до "status" в соответствии со спецификацией.

### 3. [WARNING] 🟡 Валюта передана в нижнем регистре: "usd"
- **Эндпоинт:** `/api/finance2`
- **Код правила:** `LOWERCASE_CURRENCY_CODE`
- **Ожидалось по спецификации:** `USD`
- **Фактический ответ сервера:** `usd`
- **Влияние на клиентское приложение:** Нарушение спецификации ISO 4217, риск поломки при строгом поиске в rates["usd"].
- **Рекомендация по исправлению:** Всегда сериализовать валюты в верхнем регистре (USD, EUR).
